## 💡 The Manifesto (Why NexusHub exists)

**The AI revolution fundamentally transformed GitHub's user base.**  
Alongside traditional software engineers, millions of mainstream content creators, hardware makers (ESP32 / Arduino), video editors, designers, and entrepreneurs have arrived.

Legacy GitHub search and discovery was never built for them:
- It hides behind cryptic acronyms and code files.
- It is rigged by a "Star Bias" where only viral, established projects get visibility, while **brilliant 0-star and 5-star independent creations remain completely invisible**.
- It forces you to read 500 lines of technical READMEs just to understand what a tool does.

**NexusHub is the answer:**  
Replacing cryptic names with **large, readable plain-human functions**, instant **15-second working video & GIF demos directly on the cards**, and discovering **Hidden Gems purely on merit and proof.**

---

## 🎬 The 15-Second Video & GIF Open Standard (`preview.mp4` / `preview.gif`)

NexusHub introduces an open standard for all GitHub repositories.

### How Creators Get Discovered on NexusHub:
1. Place a 15–30 second demonstration video or animated GIF in your repository root:
   - **`preview.mp4`** *(Recommended)*
   - **`preview.gif`** *(Recommended)*
   - *(or `demo.mp4`, `demo.gif`, `short.mp4`, `.github/preview.mp4`)*
2. The NexusHub crawler automatically detects it via raw GitHub HEAD requests.
3. **Your Reward:**
   - Instant front-page feature in the **▶ Short Demos** and **💎 Hidden Gems** shelves.
   - The video or GIF plays **directly on your card** so users see it working in real-time.
   - You can display the official verified badge in your README:

```markdown
[![NexusHub 15s Demo](https://img.shields.io/badge/NexusHub-15s_Demo_Verified-ec4899?style=for-the-badge&logo=youtube)](https://github.com/grezoo/nexushub)
```

## 🌟 Key Features of NexusHub

- **⚡ Function-First Typography:** Big, readable human-centric titles (e.g. *"WiFi Addressable LED Strip Controller (100+ Effects)"* instead of *"WLED"*).
- **🎞️ Direct On-Card Media:** Animated GIFs and hover-to-play MP4s right on the cards, like a streaming platform.
- **💎 Star-Independent Discovery (Hidden Gems):** Zero-star projects with working proof get top priority over high-star projects with no visual evidence.
- **🌐 Full Bilingual Experience:** Native toggle between English (default) and Hungarian (`EN / HU`).
- **📚 Universal Taxonomy:** Covers the entire spectrum from **Hardware & IoT (ESP32, Arduino, Klipper, Betaflight)** to **Generative AI, GameDev, Music & DAWs, Self-Hosted Servers, and Productivity**.
- **⊞ Grid & ☰ Netflix-Style Shelves:** Browse by horizontal thematic rails or a dense cards grid.

## 🚀 Quick Start (Running Locally)

Zero external dependencies required! Runs with standard Python (Python 3.8+):

```bash
# Clone the repository
git clone https://github.com/grezoo/nexushub.git
cd nexushub

# Start the local server
python server.py
```

Then open your browser at:  
👉 **`http://localhost:8765`**
